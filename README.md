# University Projects

This repository contains a small collection of university projects focused on embedded systems, electronics, and interactive hardware.

The projects were developed as practical exercises to explore sensors, displays, control logic, and real-time interaction with hardware.

## Projects

### 1. Spektrum Visualizer
- ESP32-based audio spectrum visualizer
- Reads audio signals from a spectrum analyzer module
- Displays the signal on a 64x32 RGB LED matrix
- Demonstrates analog input processing and real-time visualization

### 2. Snake
- Classic Snake game implemented on a LED matrix
- Controlled via joystick and speed potentiometer
- Includes game logic, collision detection, and score handling
- Example for embedded control and interactive game development

### 3. XY Plotter
- Two-axis drawing/plotter project
- Uses joystick input and stepper motors for positioning
- Includes menu navigation on an LCD display
- Demonstrates motor control and coordinate-based movement

### 4. Pong Arduino
- Simple Pong game on Arduino hardware
- Uses a display and controller inputs for gameplay
- Focuses on real-time interaction and game state logic

## Technologies used
- Arduino / C++
- ESP32
- Joystick input
- Stepper motors
- LED matrices
- LCD displays
- Sensors and analog signal processing

## Goals
These projects were created to:
- learn microcontroller programming
- work with physical inputs and outputs
- understand embedded system design
- build interactive prototypes and visual feedback systems

## Status
The projects are mainly prototype and university learning projects. 
They are intended to demonstrate practical engineering work, experimentation, and iterative development.
